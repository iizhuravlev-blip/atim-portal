# АТИМ Управление — центральная страница

Точка входа платформы «АТИМ Управление»: виджеты модулей на одном экране. Здесь видно
новые письма в СЭД, задачи в CRM, встречи на сегодня, все мои задачи, а также заглушки
будущих модулей «Маркетинг» и «Финансы». Клик по виджету ведёт в модуль к нужной записи.

**Статус (29.10.2026):** первая версия. Работают «Документооборот», «Mind CRM» и сводные «Задачи»;
«Календарь» ждёт API виджетов у группового бота; «Маркетинг» и «Финансы» — заглушки.

## Запуск локально

```bash
python -m venv .venv
.venv/Scripts/pip install -r service/requirements.txt
cd service
DATA_DIR=./data ../.venv/Scripts/python -m uvicorn app.main:app --port 8770
```

Без `SED_TOKEN` и `CRM_TOKEN` виджеты показывают «Подключается»; вход — демо-сотрудник (`AUTH_MODE=dev`).
Настройки для сервера — `service/.env.example`. Тесты: `cd service && ../.venv/Scripts/python -m pytest`.

## Состав репозитория

| Путь | Что это |
|---|---|
| [`docs/prompt.md`](docs/prompt.md) | ТЗ / промт для разработки центральной страницы |
| [`docs/widgets.md`](docs/widgets.md) | Общий контракт виджетов: что каждый модуль отдаёт порталу |
| `service/app/main.py` | сбор виджетов модулей параллельно, кэш, единый вход, раскладка сотрудника |
| `service/app/static/` | интерфейс без сборки; `atim.css` — общий стиль платформы |

## Виджеты первой версии

| Виджет | Источник | Что показывает |
|---|---|---|
| Документооборот | СЭД (`atim-docs`) | новые письма на регистрацию, на подпись, мои поручения |
| Mind CRM | `atim-crm` | мои задачи в CRM, сделки в работе |
| Маркетинг | — | заглушка |
| Финансы | — | заглушка |
| Календарь | `group-calendar-bot` | мои встречи сегодня |
| Задачи | бот + СЭД | все мои задачи и поручения в одном списке |

Предложены также виджеты «Тендеры», «Договоры», «Переговорная», «Быстрый ввод».

## Ключевые решения

- **Размещение:** сервер `mind`, Caddy проекта `/opt/wisemapping`; адрес уточняется.
- **Вход:** единый, через ядро в СЭД.
- **Данные:** портал хранит только настройки и раскладки, данные модулей не копирует.
