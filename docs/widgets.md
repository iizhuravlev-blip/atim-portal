# Контракт виджетов «АТИМ Управление»

Каждый модуль платформы отдаёт центральной странице свой виджет по одному формату.
Центральная страница сама ничего не считает: она получает готовые данные модуля и рисует их.

## Запрос

```
GET https://<модуль>/api/v1/widget
Authorization: Bearer <PORTAL_TOKEN модуля>
X-Atim-User: <id сотрудника в ядре СЭД>
```

- Запрос делает **сервер портала**, а не браузер. Токены модулей хранятся только на сервере.
- `X-Atim-User` — сотрудник, для которого считаются данные. Модуль проверяет, что такой
  сотрудник есть в ядре и активен, и учитывает его роль и организации (АТ / АР).
- Ответ — не дольше 2 секунд. Тяжёлые подсчёты модуль кэширует у себя.
- Модуль может отдать несколько виджетов: `GET /api/v1/widget?id=<id>`. Список —
  `GET /api/v1/widgets` → `[{"id": "...", "title": "..."}]`.

## Ответ

```json
{
  "id": "docs.mail",
  "title": "Документооборот",
  "status": "ok",
  "metric": { "value": 7, "label": "новых писем", "tone": "warn" },
  "badges": [ { "label": "АТ", "value": 5 }, { "label": "АР", "value": 2 } ],
  "secondary": [
    { "label": "на подпись", "value": 2, "url": "https://docs.atimlab.ru/#sign", "tone": "danger" }
  ],
  "items": [
    {
      "title": "АНО «ЦПИИ»: о переносе средств на этап 2",
      "subtitle": "info@atim.tech · 3 вложения",
      "time": "2026-10-29T08:41:00+03:00",
      "url": "https://docs.atimlab.ru/#mail/412",
      "tone": "normal"
    }
  ],
  "actions": [ { "label": "Открыть очередь", "url": "https://docs.atimlab.ru/#mail" } ],
  "url": "https://docs.atimlab.ru/",
  "updated_at": "2026-10-29T09:10:00+03:00"
}
```

| Поле | Обязательно | Смысл |
|---|---|---|
| `id`, `title` | да | идентификатор и заголовок виджета |
| `status` | да | `ok` — данные есть; `empty` — всё сделано, показать спокойное «Нет новых»; `stub` — модуль в разработке; `error` — модуль ответил, но данные получить не смог (`message` с причиной) |
| `metric` | нет | главное число виджета; `tone`: `normal` / `good` / `warn` / `danger` |
| `badges` | нет | разбивка главного числа (например по организациям) |
| `secondary` | нет | 1–3 дополнительных счётчика со ссылками |
| `items` | нет | до 5 строк; время — ISO 8601 с часовым поясом |
| `actions` | нет | кнопки-ссылки (до 2) |
| `url` | да | куда ведёт клик по заголовку |
| `updated_at` | да | когда данные посчитаны |

Ошибки транспорта (таймаут, 5xx, 401) портал показывает сам: «Нет связи с модулем»,
время последних успешных данных из кэша и ссылку на модуль. Страница целиком не падает.

## Виджеты-заглушки

Для модулей, которых ещё нет, портал отдаёт виджет сам, без запроса:
`{"id": "marketing", "title": "Маркетинг", "status": "stub", "url": "", ...}`.
Когда модуль появится, в настройках портала меняется только адрес источника.

## Безопасность

- Токен у каждого модуля свой (`PORTAL_TOKEN`), задаётся в `.env` модуля и портала.
- Модули на другом сервере (групповой бот на сервере calendar-bot) открывают `/api/v1/widget`
  в своём Caddy только для IP сервера `mind`.
- В `items` не передаются тексты документов и персональные данные сверх заголовка:
  конфиденциальные документы СЭД показываются как «Конфиденциальный документ».
